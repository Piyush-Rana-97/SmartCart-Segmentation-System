# SmartCart-Segmentation-System

SmartCart Segmentation System is an Unsupervised Machine Learning project that segments customers into meaningful groups based on their purchasing and behavioral characteristics. The project applies clustering techniques to identify hidden patterns and customer segments without using predefined target labels.

## Project Workflow
- Data Preprocessing
- Handling Missing Values
- Feature Engineering
- Outlier Detection
- Correlation Analysis using Heatmap
- Categorical Data Encoding
- Feature Scaling
- Dimensionality Reduction using PCA
- 3D Cluster Visualization
- Finding Optimal K using the Elbow Method
- Cluster Evaluation using Silhouette Score
- K-Means Clustering
- Agglomerative Clustering
- Cluster Analysis and Interpretation
